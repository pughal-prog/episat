# Scientific Limitations & Ethical Guardrails

## Core Scientific Constraints
1. **No Direct Pathogen Detection**: Satellite sensors measure environmental indicators (vegetation moisture, surface wetness, land surface temperature), not mosquitoes or viral pathogens directly.
2. **Correlation vs Causation**: Predictions represent vector breeding suitability and epidemiological transmission risk, not confirmed clinical diagnoses.
3. **Decision Support Only**: Model output is designed strictly as a public health decision-support tool for municipal vector control units, not individual medical diagnosis.
4. **Synthetic Data Disclosure**: In DEMO MODE, model metrics are calculated against synthetic time-series distributions. Validation against live municipal health surveillance data must precede real-world deployment.
